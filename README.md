# 🌐 Simple Webpage Project

This project is a basic example of a static HTML webpage that includes a heading, a paragraph, and an image. It's a great starting point for beginners learning the structure of a basic webpage using HTML and inline CSS.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3 (inline styling)**

---

## 📄 Description

The webpage consists of:

- A centered heading using `<h1>`
- A descriptive paragraph using `<p>`
- An image displayed using the `<img>` tag with responsive sizing and rounded corners
